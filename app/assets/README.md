# Offline map background

I use the Natural Earth 1:110m country boundaries as map context. I downloaded the GeoJSON from the [Natural Earth repository](https://github.com/nvkelso/natural-earth-vector) on 2026-10-15. Natural Earth releases this data into the public domain. See its [terms](https://www.naturalearthdata.com/about/terms-of-use/).

I store the map geometry locally. It adds no school attributes and does not use hosted map tiles. The country boundaries are generalized.
